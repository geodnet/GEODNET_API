# GEODNET API

This give the GEODNET API reference, which includes the following APIs.

## [GEODNET RTK API](GEODNET_RTK_API.md)

This API show how to use the GEODNET RTK API to manage RTK accounts. The enterprise RTK reseller customers can use the RTK API to create and manage RTK accounts directly.  

## [GEODNET RAWDATA API](GEODNET_RAWDATA_API.md)

The station API is used to access the GEODNET base station information. This is for the raw data customers to check the GEODNET base station data information.  

## [GEODNET PPK API](GEODNET_PPK_API.md)

This PPK API is used to download the rtcm data log files for each base station, the rtcm log file can be convert to RINEX file to be used for Post-Processing Kinematic applications (PPK)  

## [GEODNET GGA API](GEODNET_GGA_API.md)

The GGA API provides access to real-time NMEA GGA position data uploaded by rovers connected to the GEODNET network. Developers can use this API to monitor rover locations and integrate position data into fleet management systems, operational dashboards, and analytics platforms.

## [GEODNET KB API](GEODNET_KB_API.md)

The GEODNET Knowledge Center provides background information and practical guidance on GNSS, RTK positioning, NTRIP, and RTCM. It covers network architecture, hardware and setup, surveying concepts, and applications to help users understand and work with RTK services.
